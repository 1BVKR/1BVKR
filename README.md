## 🚀 Projects

### 🔒 Door Intrusion Detection System
> **LPC1768 · ARM Cortex-M3 · GSM SIM800L · Keil µVision**

Real-time door intrusion detection with SMS alert over GSM. Integrated IR sensor, 4×4 keypad, LCD display, PWM servo control, and UART-based SIM800L communication — all in a single Embedded-C firmware on LPC1768.

- Interrupt-driven IR sensor detection
- SMS alert sent via SIM800L (UART1) on intrusion
- Keypad-based arm/disarm with LCD feedback
- PWM servo for physical lock control
